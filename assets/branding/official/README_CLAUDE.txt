UNIMATE.AZ — LOGO ASSET PACK

IMPORTANT BRAND RULE
Use the supplied logo artwork exactly as provided. Do not redraw, distort, rotate,
reconstruct, change proportions, alter letterforms, add effects, or modify the cap/U/sparkle.
Use the transparent PNG assets in this pack. Preserve aspect ratio.

FOLDERS
- PNG/Full_Logo: complete logo lockup (symbol + UNIMATE.AZ + TƏLƏBƏ PLATFORMASI)
- PNG/Icon_Only: standalone symbol for app icon, favicon, avatar, loading states and compact UI
- PNG/Wordmark: wordmark/tagline lockup without the symbol

COLOR VARIANTS
- Original_Gradient: original blue/purple gradient and navy wordmark; preferred primary version
- White: for dark or saturated backgrounds
- Navy: for light backgrounds and restrained corporate layouts
- Black: monochrome / print fallback
- Slate: muted neutral fallback

USAGE
- Light backgrounds: Original_Gradient or Navy.
- Dark backgrounds: White.
- Small spaces: Icon_Only; do not squeeze the full logo into a small slot.
- App icon: place Icon_Only centered on a brand-colored or neutral square background;
  do not bake a background into the transparent PNG.
- Maintain clear space around the artwork and never stretch it.
- Use Full_Logo where the brand name and descriptor need to be visible.
- Use Wordmark only when the symbol is already present nearby or the layout requires a horizontal/text-led lockup.

TRANSPARENCY
All PNGs have transparent backgrounds. They are intended to be placed over the design's
actual background. Do not add a white rectangle behind them.

CLAUDE / DESIGN-AGENT INSTRUCTION
Treat this folder as the single source of truth for UNIMATE.AZ branding. Before creating
or editing any UNIMATE.AZ screen, website section, social post, presentation, mockup,
app icon, favicon, or marketing asset, inspect this asset pack and choose the correct
variant and lockup for the background and available space. Prefer Original_Gradient on
light backgrounds and White on dark backgrounds. Use Icon_Only for compact placements.
Never recreate the logo with text, CSS, SVG approximations, AI generation, or substitute
symbols. Never alter the logo artwork. Keep its original proportions, colors/gradient,
lettering, spacing, and transparency. If a required format or size is missing, export
from the provided transparent PNG without changing the artwork.
